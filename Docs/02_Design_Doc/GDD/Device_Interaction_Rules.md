# Moth Effect（飞蛾效应）：道具与交互规则

版本 v0.7　日期 2026-10-03　性质 建议工作基线　状态 尚未实现

本文件定义能直接转成代码和测试的行为契约。用户已经确认三种机关、拾取、投掷和空中射击；以下触发条件、状态和边界处理是建议基线。参数数值只在 [玩法参数基线](Gameplay_Parameters.json) 维护，自定义类与接口只在 [技术设计](../TDD/Technical_Design.md) 维护。规则改变必须更新 [设计决策](../TDD/Decisions/Design_Decisions.md) 及关联验收项。

## 1 统一规则

| 规则 ID | 规则 | 可观察结果 |
| --- | --- | --- |
| R01 | 每个敌人死亡结算一次，在死亡位置生成固定类型的一件道具 | 同帧重复伤害不产生第二件掉落 |
| R02 | 仅有效弹丸命中可启动 Dormant，道具不因身体碰撞或爆炸伤害启动 | 玩家枪、敌人弹、机关弹都能触发；普通碰撞只推动 |
| R03 | 同一件道具仅允许一次 Dormant 到 Active 的转换 | 同帧多次命中只有一次爆炸或启动 |
| R04 | 未激活道具可拾取、放下和投掷；Held 不可激活且不模拟物理 | 携带物不在手中误爆，但玩家仍会受伤 |
| R05 | 触发来源不按阵营限制，角色伤害同样不按阵营限制 | 敌人子弹能启动道具，机关火力会伤敌我 |
| R06 | 启动后不可拾取或重复启动；结束进入 Spent 并清理 | 玩家不会把工作中的发射器收回 |
| R07 | D01 向下探测可承托静态表面，固定该落点生成升降柱 | 空中启动也在其下方起柱 |
| R08 | 每根柱子一次伸出，对每个目标仅施加一次弹射 | 持续重叠不会每帧叠加速度 |
| R09 | D02 在当前位置爆炸，角色受伤害和推力，道具只受推力 | 装置被炸开而不形成自动引爆链 |
| R10 | D03 锁定激活弹丸的世界飞行方向，方向不随装置翻滚或玩家转身改变 | 移动中仍保持同一射击方向 |
| R11 | Active D03 保持物理运动，可被柱子和爆炸推开 | 空中火线随装置位移 |
| R12 | 一个飞行弹丸首次阻挡命中后消耗，一次命中只产生一次处理 | 无反弹、穿透和同帧多次启动 |
| R13 | 同一次左键按下负责投掷，释放后下一次按下才允许枪械开火 | 连按或长按不会意外启动刚抛出的机关 |
| R14 | 投掷与放下必须先检测前方空间；阻挡时保持 Held 并提示 | 道具不会从身体或墙内生成 |
| R15 | Dormant 采用累计闲置时间，最后阶段提示过期；Held 暂停该计时 | 拾取放下不刷新整段寿命 |
| R16 | 数量受全场安全上限约束，清理策略明确且优先保留 Held 和 Active | 道具不会无界增长或突然从手里消失 |
| R17 | 胜负、暂停和重开统一管理生成、计时与伤害 | 结算停止攻击，重开没有上一局遗留 |
| R18 | 道具球形射击判定、镜头遮挡与枪口阻挡统一处理 | 不会穿墙拾取、穿掩体开火或靠判定打到遮挡后的道具 |

R02 的弹丸包含命中扫描步枪造成的命中事件。爆炸不触发机关，是为保留玩家对启动时机的控制；发射装置的子弹仍可串联启动其他装置。若原型证明爆炸触发更好，需要明确变更 R02/R09，而不是只在某个道具蓝图里偷偷加入例外。

## 2 状态与输入

~~~text
生成 → Dormant
Dormant → Held → Dormant
Dormant → Active → Spent → Destroyed
Dormant 过期 → Spent → Destroyed
任何非销毁状态 → 本局统一清理 → Destroyed
~~~

Held 仅由拥有者安全放下或投掷恢复 Dormant。Active 不是 Held 的直接后继。Destroyed 是生命周期终止的逻辑状态，可通过对象已销毁体现。

| 状态 | 可拾取 | 物理运动 | 接受弹丸启动 | 主要计时 |
| --- | --- | --- | --- | --- |
| Dormant | 是，需距离与视线 | 是，可落地休眠 | 是 | 累计闲置剩余时间 |
| Held | 由拥有者控制放下/投掷 | 否，附着角色 | 否，射击检测忽略 | 闲置时间暂停 |
| Active D01 | 否 | 种子消耗，柱子固定落点 | 否 | 伸出、停留、收回 |
| Active D02 | 否 | 立即结算一次 | 否 | 结束效果后清理 |
| Active D03 | 否 | 是 | 否，阻挡弹丸但不再次启动 | 发射与有效期 |
| Spent | 否 | 无交互碰撞 | 否 | 立即移出计数，短效果后销毁 |

普通状态 E 拾取准星候选道具；持有状态 E 放下。候选必须在拾取半径内、没有墙体遮挡、状态为 Dormant。已有 Held 时不直接切换另一件道具，避免隐式抛弃当前物品。

持有时左键启动一次投掷。动作完成后恢复步枪，但必须同时满足左键已松开和 [Gameplay_Parameters.json.throw.minGunRecoverySeconds](Gameplay_Parameters.json) 的恢复时间已结束，下一次按下才允许射击；R 换弹在持有状态不生效。暂停、结算或死亡时锁定交互输入。

## 3 命中上下文

每次命中至少携带 SourceActor、InstigatorPawn、ImpactPoint、ShotDirection、Damage、HitId，与 [技术设计](../TDD/Technical_Design.md) 的 FHitContext 同名。ShotDirection 是命中前弹丸的世界单位速度方向；步枪用实际枪口射线的单位方向。不能用表面法线、玩家之后的朝向或装置旋转替代。飞行弹丸 HitId 沿用其出生时唯一 ID；命中扫描每一枪生成新 ID。

飞行弹丸忽略生成它的发射器或射手自身，其他目标按规则处理。忽略生成者仅避免出生自撞，不给其角色额外的爆炸免伤。敌人和机关共用弹丸处理路径。

命中 Dormant 时，先以幂等检查锁定 Active，再执行效果。命中 Active 时只消耗弹丸，装置不重置寿命、不更改方向。角色受伤与道具激活是分别处理的目标类型，不能把道具当作血量归零后才启动。

## 4 弹射装置 D01

流程：命中锁定 Active → 沿世界负 Z 探测 → 验证承托表面及整个最终柱体空间 → 生成柱子 → 扫描伸出过程中覆盖的角色/道具 → 对每个目标施加一次向上速度 → 停留与收回 → 清理。

承托表面必须位于探测距离内，表面向上法线满足配置阈值，并被关卡标为可起柱。高台顶面可以标记为可承托表面；纯装饰、动态道具和其他柱子不作为地面。探测失败时消耗道具并播放明显的失效反馈，不在无限深处或天空生成柱子。

柱子落点按激活时的位置固定。最终柱体体积被不可移动几何或天花板阻挡时采用同样失效处理；移动角色在柱子作用范围内属于正常弹射对象。生成柱子后，来源种子关闭本体可见、碰撞与物理，保留逻辑 Active 和同一名额直到柱子结束，不作为净空检查的占用物。

角色使用运动组件的速度处理，可移动道具使用物理速度处理。弹射保留水平速度，把竖直速度设置为 [玩法参数基线](Gameplay_Parameters.json) 对应的目标值，柱子不直接造成伤害。P0 无坠落伤害，场地外安全处理见第 9 节。每个目标在本次柱子工作期间最多弹射一次，包括后来移动到柱体伸出区域的目标；伸出结束后不再新增弹射。

柱子升起阶段关闭实体阻挡，以查询体积执行弹射，避免主动弹射与物理挤压叠加。完全伸出后，在停留阶段检查柱体体积是否已无角色及物理道具；净空才启用实体支撑与弹道阻挡，未净空就等待至停留结束，不强行夹住目标。收回前先关闭实体碰撞。矩阵中的柱子阻挡只在该实体阶段生效。

## 5 爆炸装置 D02

流程：命中锁定 Active → 固定爆心 → 对半径内去重后的角色结算一次伤害 → 对有无遮挡作用路径的目标施加推力 → Spent → 效果结束销毁。

建议初版范围内固定伤害；距离衰减延期。伤害与推力都受静态实体掩体遮挡，以爆心到目标代表点的静态遮挡查询为准。同一角色的多个碰撞组件不能导致多次伤害。

水平推力沿爆心到目标的水平径向，附加向上速度；若水平距离为零，采用激活弹丸方向的水平投影，仍为零时采用固定世界前向。推力有速度上限，以免叠加把对象送出场地。

Dormant 道具和 Active D03 接受推力，Held 道具不单独运动，柱子固定不被移动。角色持有道具时仍承受爆炸伤害和推力。爆炸不调用其他道具的激活接口。

同一帧多个外部推力先按目标合并全部爆炸速度增量，再应用本帧柱子的目标 Z 速度，最后按 [Gameplay_Parameters.json.limits.maxExternalVelocityCmPerSec](Gameplay_Parameters.json) 限制速度大小。角色和可移动道具使用同一处理顺序，避免回调次序改变结果。

## 6 发射装置 D03

流程：锁定 Active 与 Direction → 发射方向可见提示 → 等待短启动延迟 → 按固定间隔生成 P01 → 到期停止计时 → Spent → 清理。

方向固定在世界空间。装置受重力、碰撞和推力影响，弹丸出生点跟随装置位置移动；外观发射口或方向标记必须与固定方向一致，不能展示为朝另一侧发射。

启动后第一发与后续发射时刻由 [玩法参数基线](Gameplay_Parameters.json) 规定。到期时先停止计时，严格小于有效期的发射时刻才可生成弹丸。出生点被世界静态几何阻挡时消耗该发，不在墙内生成弹丸；不因此延长工作时间。

## 7 交互矩阵

| 来源 | 角色 | Dormant 道具 | Held 道具 | Active D03 | 固定柱子 |
| --- | --- | --- | --- | --- | --- |
| 玩家步枪命中 | 伤害 | 激活一次 | 忽略 | 阻挡，子弹消耗 | 阻挡 |
| 敌人或机关弹丸 | 伤害并消耗 | 激活并消耗 | 忽略 | 阻挡并消耗 | 阻挡并消耗 |
| 爆炸 | 伤害与推力 | 推动，不激活 | 跟随持有者 | 推动，不重启 | 不移动 |
| 柱子伸出 | 弹射一次 | 弹射一次 | 跟随持有者 | 弹射一次 | 无相互起柱 |
| 身体碰撞 | 正常阻挡 | 正常推动 | 忽略独立碰撞 | 正常推动 | 正常支撑/阻挡 |

矩阵不包括发射者对自己生成弹丸的出生避让，见第 3 节。碰撞通道配置见 [技术设计](../TDD/Technical_Design.md)，不能只按 Pawn/WorldDynamic 一类粗略过滤全部道具。

## 8 数量与计时边界

计数范围：Dormant、Held、Active 种子或装置各算一件道具；D01 从种子到柱子的转换沿用同一名额，不重复计入。Spent 立即移出计数，残留视觉效果不再参与玩法。已经飞出的弹丸独立采用寿命及弹丸上限。

总道具满额且有新掉落时，清理最早生成的 Dormant 再生成新道具；没有 Dormant 时不生成本次掉落，并给出短提示。Held 和 Active 不被该策略抢占。直接生成新物件前检查容量，不能先超额再等待下帧清理。

同类 Active 柱子或发射器满额时，启动新装置前结束最早启动的同类装置，再开始新的。关闭发射器计时器；柱子先释放 Active 名额并关闭实体碰撞，进入收回流程且不再弹射。无法安全释放名额时拒绝新启动，保持 Dormant 并提示，命中弹丸仍消耗。此为安全策略，正常三波应很少触及，测试必须覆盖。

飞行弹丸达到上限时，本次生成失败并消耗该发，不延长发射器有效期或追加补发；敌人的射击也共用该限制。P01 为直线低速弹丸，重力系数为零；这是弹丸的规则，D03 机身仍保持重力。

Dormant 累计闲置计时在 Held 时暂停、恢复时继续；Active 使用自身工作寿命。玩家死亡时 Held 道具随本局清理，不额外生成死亡掉落。暂停时所有玩法计时、物理和弹丸均停止，界面输入仍可工作。

## 9 关卡边界与重开

目标对象离开关卡安全体积时：玩家判负进入重开界面；敌人只注销一次并结算该波计数，不生成界外掉落；道具和弹丸清理并释放名额。以安全体积保证活着的敌人不能永久卡在地图外。

重开复位血量、弹药、输入持有锁、波次、所有临时对象、计时器、道具计数和掉落结算记录。推荐重新加载本关作为 P0 重开方式。开始新波不等于重开：有效的未激活道具按剩余寿命保留，过期规则仍生效。清波必须同时满足存活敌人数为零和待生成敌人数为零，不能在两批之间提前进入下一波。

## 10 必须记录的原型问题

| 验证 ID | 观察问题 | 可调手段 | 不应偷偷改变的规则 |
| --- | --- | --- | --- |
| V01 | 道具空中是否经常出镜或难以命中 | 相机偏移、尺寸、轨迹、判定球 | 不加入穿墙自动命中 |
| V02 | 玩家是否能预判发射方向 | 箭头、短引导线、启动延迟 | 不改成自动追踪 |
| V03 | 弹射是否看得懂且能利用 | 柱高、时间、推力、声音 | 不让持续重叠反复加速 |
| V04 | 连锁是否可复现 | 布局、节奏、提示、数量 | 不为固定组合另写技能脚本 |
| V05 | 友军伤害是否过于突然 | 敌弹速度、预警、伤害与装置密度 | 例外免伤须作为规则变更记录 |
