# Moth Effect（飞蛾效应）：道具与交互规则

版本 v0.14　日期 2026-10-17　性质 出生保护与发射器自动索敌由用户要求　状态 本轮专项验证与硬件 PIE 按交付记录验收

本文件定义能直接转成代码和测试的行为契约。用户已经确认三种机关、拾取、投掷和空中射击；以下触发条件、状态和边界处理是建议基线。参数数值只在 [玩法参数基线](Gameplay_Parameters.json) 维护，自定义类与接口只在 [技术设计](../TDD/Technical_Design.md) 维护。规则改变必须更新 [设计决策](../TDD/Decisions/Design_Decisions.md) 及关联验收项。

2026-10-17 用户要求道具刚出现时不能触发，发射器自动瞄准范围内最近敌人。现行规则新增出生保护；D03 接纳激活时锁定最近存活敌人的三维射向，无目标时沿用入射 XY 投影。地面固定、显式外力、统一效果延迟及爆炸激活继续保留。历史构建和测试结果归属当时规则，现行配置与本轮验收见 [重构接入](../../05_Development_Guide/Device_Refactor_Setup.md)。

v0.9 的玩家方案与新增 R19–R23 已由用户确认；R13/R14 的按压与安全释放继续采用已确认玩家方案。其余机关规则保留此前来源状态，不将本次玩家确认扩大为全部建议或数值已经实测。玩家行动状态的唯一结构定义见 [技术设计第 3 节](../TDD/Technical_Design.md#3-越肩射击与输入)，下文只维护操作结果。

现行契约覆盖 D01–D03。牵引核心、诱光灯、折光棱镜、静滞锚和换位匣记录在 [候选机关道具](Device_Candidates.md)，均待选制作。其中反射和静滞涉及对 R12、R11 的扩展，选定前不作为本规则的例外。

## 1 统一规则

| 规则 ID | 规则 | 可观察结果 |
| --- | --- | --- |
| R01 | 每个敌人死亡结算一次，在死亡位置生成固定类型的一件道具 | 同帧重复伤害不产生第二件掉落 |
| R02 | 出生保护结束后，有效弹丸命中及 D02 范围内无遮挡爆炸可启动 Dormant；身体碰撞不启动 | 三类道具从 BeginPlay 起按游戏时间计算保护期，期间命中仍消耗弹丸但不排队激活；拾取和显式推力不受保护期影响 |
| R03 | 同一件道具仅允许一次 Dormant 到 Active；接纳即锁首次证据并占容量，统一延迟后执行效果 | 等待期不能拾取，重复命中不刷新延迟、不重复爆炸或启动 |
| R04 | 未激活道具可拾取、放下和投掷；Held 不可激活且不模拟物理 | 携带物不在手中误爆，但玩家仍会受伤 |
| R05 | 触发来源不按阵营限制，角色伤害同样不按阵营限制 | 敌人子弹能启动道具，机关火力会伤敌我 |
| R06 | 启动后不可拾取或重复启动；结束进入 Spent 并清理 | 玩家不会把工作中的发射器收回 |
| R07 | D01 向下探测可承托静态表面，固定该落点生成升降柱 | 空中启动也在其下方起柱 |
| R08 | 每根柱子一次伸出，对每个目标仅施加一次弹射 | 持续重叠不会每帧叠加速度 |
| R09 | D02 接纳激活时锁世界爆心，统一延迟后爆炸；角色受伤害与推力，无遮挡 Dormant 道具受推力并请求激活 | 下游设备继承各自统一延迟；Held 不激活，Active 不重启 |
| R10 | D03 接纳激活时按当前位置的三维距离搜索范围内最近有效存活敌人，锁定指向其 Actor 中心的三维单位方向；无目标沿用入射 XY 投影，纯竖直命中回退世界 +X | 只索敌一次，不随敌人移动/死亡、玩家转向、机身翻滚或重复命中改变方向；不同高度的目标可产生俯仰射向 |
| R11 | Dormant 与 Active D03 落地停止物理且实体根无碰撞；显式柱子/爆炸外力唤醒空中物理，再落地固定 | 地面可穿行而仍能射击/拾取；被弹起的发射器火线随位移 |
| R12 | 一个飞行弹丸首次阻挡命中后消耗，一次命中只产生一次处理 | 无反弹、穿透和同帧多次启动 |
| R13 | 同一次左键按下负责投掷，释放后下一次按下才允许枪械开火 | 连按或长按不会意外启动刚抛出的机关 |
| R14 | 投掷与放下必须先检测前方空间；阻挡时保持 Held 并提示 | 道具不会从身体或墙内生成 |
| R15 | Dormant 采用累计闲置时间，最后阶段提示过期；Held 暂停该计时 | 拾取放下不刷新整段寿命 |
| R16 | 数量受全场安全上限约束，清理策略明确且优先保留 Held 和 Active | 道具不会无界增长或突然从手里消失 |
| R17 | 胜负、暂停和重开统一管理生成、计时与伤害 | 结算停止攻击，重开没有上一局遗留 |
| R18 | 落地待拾取道具使用敌人大小的胶囊统一受击与准星拾取判定；飞行和激活状态使用原射击球 | 模型在掉落胶囊中心匀速旋转；镜头遮挡与枪口阻挡仍生效 |
| R19 | 持枪与携带时沿镜头水平朝向转身，移动支持八方向；镜头俯仰不倾斜角色本体 | 侧移/倒退时仍可向准星方向射击或投掷 |
| R20 | 正常、瞄准、携带共用单 Jog 速度；取消走路/冲刺切换，Shift 不改变速度；携带时仍可移动与跳跃 | 2026-10-08 用户更改移动方案；速度只维护在参数基线，瞄准/开火不再触发速度切换 |
| R21 | 换弹中可移动/跳跃/瞄准并尝试拾取；成功拾取取消未完成换弹，失败不取消；普通受伤不打断换弹 | 取消不补弹，迟到回调不影响持物或下一次换弹 |
| R22 | 腾空、受伤和落地不附加强制操作硬直；存活且行动许可时可控制视角、瞄准与射击 | 柱子或爆炸把玩家送入空中后仍能完成核心操作，携带时仍遵守禁枪规则 |
| R23 | 空匣不射击、不自动换弹；使用 R 请求有效换弹，满匣/持物时不启动 | 弹药不为负，未完成或取消换弹不补弹，无无限备用弹导致的自动开火循环 |

R02 的弹丸包含命中扫描步枪造成的命中事件。爆炸经范围、静态遮挡、状态与幂等检查请求 TryActivate，不依赖伪造弹丸碰撞；普通地面/机身碰撞仍不触发机关。出生保护时长只在 [参数账本](Gameplay_Parameters.json) 的 device.spawnActivationProtectionSeconds 维护；以 BeginPlay 的游戏时刻为起点，暂停冻结，拾取/放下/投掷均不重置保护期。保护期拒绝发生在接纳 Active 和占用容量之前，结束后需要新的一次有效触发。

## 2 状态与输入

~~~text
生成 → Dormant
Dormant → Held → Dormant
Dormant → Active → Spent → Destroyed
Dormant 过期 → Spent → Destroyed
任何非销毁状态 → 本局统一清理 → Destroyed
~~~

Held 仅由拥有者安全放下或投掷恢复 Dormant。Active 不是 Held 的直接后继。Destroyed 是生命周期终止的逻辑状态，可通过对象已销毁体现。

| 状态 | 可拾取 | 物理运动 | 接受弹丸启动 | 主要计时 |
| --- | --- | --- | --- | --- |
| Dormant | 是，需距离与视线 | 地面固定；投掷/显式外力后空中物理 | 出生保护结束后接受弹道及无遮挡 D02 激活 | 出生保护与累计闲置剩余时间 |
| Held | 由拥有者控制放下/投掷 | 否，附着角色 | 否，射击检测忽略 | 闲置时间暂停 |
| Active D01 | 否 | 种子消耗，延迟后柱子固定落点 | 否 | 统一延迟、伸出、停留、收回 |
| Active D02 | 否 | 等待期沿地面固定/空中物理处理，爆心不变 | 否 | 统一延迟、一次结算、短效果清理 |
| Active D03 | 否 | 地面固定，显式外力后空中物理 | 否，阻挡弹丸但不再次启动 | 统一延迟，随后发射与有效期 |
| Spent | 否 | 无交互碰撞 | 否 | 立即移出计数，短效果后销毁 |

普通状态 E 拾取准星候选道具；持有状态 E 放下。候选必须在拾取半径内、没有墙体遮挡、状态为 Dormant。已有 Held 时不直接切换另一件道具，避免隐式抛弃当前物品。

持有时左键启动一次投掷。动作完成后恢复步枪，但必须同时满足左键已松开和 [Gameplay_Parameters.json.throw.minGunRecoverySeconds](Gameplay_Parameters.json) 的恢复时间已结束，下一次按下才允许射击；R 换弹在持有状态不生效。暂停、结算或死亡时锁定交互输入。

物理释放成功才开始恢复计时；放下没有投掷恢复阶段，释放受阻继续 Held。恢复期间提前再按左键不会缓存射击或在计时结束时自动开枪，需再松开后重新按；提示恢复中。玩家行动恢复与本次左键归属分别检查，不能把恢复时间结束视为上一记投掷已经松键。

换弹时 E 先完整验证拾取；成功后统一取消未完成换弹并进入持物，失败则继续原换弹。仅已存活、局内许可且行动允许时接受操作；暂停冻结已有合法换弹/恢复计时，停止连射并要求实际松键后重新按。输入取消或失焦不等于实际松键。死亡/结算取消玩法任务，Held 随本局清理，不额外掉落。

## 3 命中上下文

每次命中至少携带 SourceActor、InstigatorPawn、ImpactPoint、ShotDirection、Damage、HitId，与 [技术设计](../TDD/Technical_Design.md) 的 FHitContext 同名。ShotDirection 是命中前弹丸的世界单位速度方向；步枪用实际枪口射线的单位方向。不能用表面法线、玩家之后的朝向或装置旋转替代。飞行弹丸 HitId 沿用其出生时唯一 ID；命中扫描每一枪生成新 ID。

D03 保留真实命中上下文用于来源和伤害归属，发射方向另在接纳时计算：以装置位置到有效存活 AEnemyBase 的 Actor 中心的三维距离选择范围内最近者，再锁定指向该中心的三维单位向量；不附加视线筛选或持续追踪。无有效目标时才对入射方向取 XY 投影并归一化，合法竖直方向回退世界 +X；完整零方向命中仍无效。D02 每件连锁炸弹使用自身独立的 ActivationHitId 结算本次伤害/推力，每个被爆炸激活的下游道具再生成新 HitId，来源为本次炸弹，方向为爆心到目标的径向；中心重合时使用本次激活方向的水平投影，仍为零则采用世界 +X。不能把整个连锁统一成同一个伤害 ID 而吞掉后续爆炸。

飞行弹丸忽略生成它的发射器或射手自身，其他目标按规则处理。忽略生成者仅避免出生自撞，不给其角色额外的爆炸免伤。敌人和机关共用弹丸处理路径。

命中 Dormant 时，先以幂等检查锁定 Active，再按统一延迟执行效果。命中 Active 时只消耗弹丸，装置不重置寿命、不更改方向。角色受伤与道具激活是分别处理的目标类型，不能把道具当作血量归零后才启动。

“锁定 Active”与“开始效果”分开：接纳时提交状态、首次上下文和容量，IsActivationPending 标记等待，随后使用世界 Timer 等待 [统一激活延迟](Gameplay_Parameters.json) 才执行一次效果。暂停冻结延迟；结束、禁用、销毁与本局清理取消等待。D01 探地原点和 D02 爆心在接纳时固定，D03 工作寿命在延迟结束、效果起动时开始。零延迟可用于明确的专项测试覆盖，幂等状态仍先提交。

## 4 弹射装置 D01

流程：命中锁定 Active 与原点、关闭种子运动/查询 → 等待统一延迟 → 从保存原点沿世界负 Z 探测 → 验证承托表面及整个最终柱体空间 → 生成柱子 → 扫描伸出过程中覆盖的角色/道具 → 对每个目标施加一次向上速度 → 停留与收回 → 清理。

承托表面必须位于探测距离内，表面向上法线满足配置阈值，并被关卡标为可起柱。高台顶面可以标记为可承托表面；纯装饰、动态道具和其他柱子不作为地面。探测失败时消耗道具并播放明显的失效反馈，不在无限深处或天空生成柱子。

柱子落点按激活时的位置固定。最终柱体体积被不可移动几何或天花板阻挡时采用同样失效处理；移动角色在柱子作用范围内属于正常弹射对象。生成柱子后，来源种子关闭本体可见、碰撞与物理，保留逻辑 Active 和同一名额直到柱子结束，不作为净空检查的占用物。

角色使用运动组件的速度处理，可移动道具使用物理速度处理。弹射保留水平速度，把竖直速度设置为 [玩法参数基线](Gameplay_Parameters.json) 对应的目标值，柱子不直接造成伤害。P0 无坠落伤害，场地外安全处理见第 9 节。每个目标在本次柱子工作期间最多弹射一次，包括后来移动到柱体伸出区域的目标；伸出结束后不再新增弹射。

柱子升起阶段关闭实体阻挡，以查询体积执行弹射，避免主动弹射与物理挤压叠加。完全伸出后，在停留阶段检查柱体体积是否已无角色及物理道具；净空才启用实体支撑与弹道阻挡，未净空就等待至停留结束，不强行夹住目标。收回前先关闭实体碰撞。矩阵中的柱子阻挡只在该实体阶段生效。

2026-10-11 T11 灰盒细化（DEC30）：承托 Actor 或命中组件须带 `MothColumnSurface` 标签。柱体使用与查询/实体一致的方形截面，`columnRadiusCm` 表示半宽；落点 XY 固定，底面按承托法线抬至该底座在局部支撑平面上的最高接触高度，保持世界竖直。最终体积查询仅排除底部 1cm 接触容差，不忽略整个承托 Actor/组件，保证同一网格上的墙/天花板仍能阻止生成。边缘仍以中心探地是否命中合格表面和最终空间是否净空判定，不额外承诺整块底座都有地面。失效种子进入 Spent，以红色提示和原因事件反馈；伸出结束后进入的目标不再弹射，实体等待会检查所有阻挡柱体的动态占用物。

## 5 爆炸装置 D02

流程：命中锁定 Active 与爆心 → 等待统一延迟 → 对半径内无遮挡、去重后的角色结算一次伤害 → 向合法目标提交推力及向 Dormant 道具请求激活 → Spent → 效果结束销毁。

建议初版范围内固定伤害；距离衰减延期。伤害与推力都受静态实体掩体遮挡，以爆心到目标代表点的静态遮挡查询为准。同一角色的多个碰撞组件不能导致多次伤害。

水平推力沿爆心到目标的水平径向，附加向上速度；若水平距离为零，采用激活弹丸方向的水平投影，仍为零时采用固定世界前向。推力有速度上限，以免叠加把对象送出场地。

Dormant 道具和 Active D03 接受推力；固定道具经显式外力入口起飞，再次落地固定。Held 道具不单独运动或激活，柱子固定不被移动；角色持有道具时仍承受爆炸伤害和推力。无遮挡范围内 Dormant 同时请求共用激活入口，Active 不重启。每次设备已先进入 Active，环形连锁不会重新激活先前设备；默认延迟把传播分成世界计时任务，零延迟也必须依赖已提交状态保证有限传播。

同一帧多个外部推力先按目标合并全部爆炸速度增量，再应用本帧柱子的目标 Z 速度，最后按 [Gameplay_Parameters.json.limits.maxExternalVelocityCmPerSec](Gameplay_Parameters.json) 限制速度大小。角色和可移动道具使用同一处理顺序，避免回调次序改变结果。

## 6 发射装置 D03

流程：出生保护结束 → 接纳 Active 并锁定最近存活敌人的三维 Direction（无目标采用入射水平后备）→ 发射方向可见提示 → 等待统一激活延迟 → 开始工作寿命 → 等待既有首发延迟 → 按固定间隔生成 P01 → 到期停止计时 → Spent → 清理。

目标范围来自 [参数账本](Gameplay_Parameters.json) 的 emitter.targetRangeCm，距离使用三维直线距离并包含边界；取触发时装置位置和目标 Actor 中心，只锁一次方向，不保存持续瞄准任务。装置在地面停止模拟且实体根无碰撞；空中继续重力与场景碰撞，忽略 Pawn，显式推力/弹射可令地面装置再次起飞。弹丸出生点跟随装置位置，外观发射口和方向标记使用同一锁定世界向量。

统一延迟和 D03 首发延迟分别由 [玩法参数基线](Gameplay_Parameters.json) 规定并相加；D03 有效期从效果起动开始，不把统一等待期扣进工作寿命。到期时先停止计时，严格小于有效期的发射时刻才可生成弹丸。出生点被世界静态几何阻挡时消耗该发，不在墙内生成弹丸；不因此延长工作时间。

| 玩家步枪命中 | 伤害 | 激活一次 | 忽略 | 阻挡，子弹消耗 | 阻挡 |
| 敌人或机关弹丸 | 伤害并消耗 | 激活并消耗 | 忽略 | 阻挡并消耗 | 阻挡并消耗 |
| 爆炸 | 伤害与推力 | 显式推力、无遮挡时延迟激活 | 跟随持有者，不激活 | 显式推力，不重启 | 不移动 |
| 柱子伸出 | 弹射一次 | 弹射一次 | 跟随持有者 | 弹射一次 | 无相互起柱 |
| 身体碰撞 | 正常阻挡 | 地面实体无碰撞，空中物理忽略 Pawn | 忽略独立碰撞 | 地面实体无碰撞，空中物理忽略 Pawn | 正常支撑/阻挡 |

矩阵中的 Dormant 激活均须先满足出生保护结束；保护期内爆炸仍可施加合法推力。矩阵不包括发射者对自己生成弹丸的出生避让，见第 3 节。碰撞通道配置见 [技术设计](../TDD/Technical_Design.md)，不能只按 Pawn/WorldDynamic 一类粗略过滤全部道具。

运动状态独立于 EDeviceState：IsGrounded 不是新增生命周期。地面固定关闭实体根。2026-10-16 用户调整：落地 Dormant 使用与敌人相同大小的 DroppedCollider 胶囊，受击和准星拾取共用 QueryOnly 体积，底部与物理根齐平；模型实际包围盒中心位于胶囊中心，绕竖直轴匀速旋转，默认速度见 [参数账本](Gameplay_Parameters.json) 的 device.droppedRotationDegreesPerSecond。旋转只作用于显示，暂停冻结；拾取、受力/投掷离地或激活后停止并复原显示变换。空中 Dormant 和 Active D03 使用原 ShotCollider 查询球；Held、Spent 与消耗的 D01 种子关闭全部查询体积。VisualScale 仅调整模型显示，BodyRadiusCm 与 ShotRadiusCm 分别调整飞行/安全释放体积与原射击球，Shot 不能小于 Body；不改变掉落胶囊。改大小后同步刷新并回归释放净空与命中遮挡。支持面消失时固定设备恢复下落，重新承托后再次固定。

## 8 数量与计时边界

计数范围：Dormant、Held、Active 种子或装置各算一件道具；D01 从种子到柱子的转换沿用同一名额，不重复计入。Spent 立即移出计数，残留视觉效果不再参与玩法。已经飞出的弹丸独立采用寿命及弹丸上限。

总道具满额且有新掉落时，清理最早生成的 Dormant 再生成新道具；没有 Dormant 时不生成本次掉落，并给出短提示。Held 和 Active 不被该策略抢占。直接生成新物件前检查容量，不能先超额再等待下帧清理。

同类 Active 柱子或发射器满额时，启动新装置前结束最早启动的同类装置，再开始新的。关闭发射器计时器；柱子先释放 Active 名额并关闭实体碰撞，进入收回流程且不再弹射。无法安全释放名额时拒绝新启动，保持 Dormant 并提示，命中弹丸仍消耗。此为安全策略，正常三波应很少触及，测试必须覆盖。

飞行弹丸达到上限时，本次生成失败并消耗该发，不延长发射器有效期或追加补发；敌人的射击也共用该限制。P01 为直线低速弹丸，重力系数为零；这是弹丸的规则，D03 机身仍保持重力。

Dormant 累计闲置计时在 Held 时暂停、恢复时继续；Active 使用自身工作寿命。玩家死亡时 Held 道具随本局清理，不额外生成死亡掉落。暂停时所有玩法计时、物理和弹丸均停止，界面输入仍可工作。

## 9 关卡边界与重开

目标对象离开关卡安全体积时：玩家判负进入重开界面；敌人只注销一次并结算该波计数，不生成界外掉落；道具和弹丸清理并释放名额。以安全体积保证活着的敌人不能永久卡在地图外。

重开复位血量、弹药、输入持有锁、波次、所有临时对象、计时器、道具计数和掉落结算记录。推荐重新加载本关作为 P0 重开方式。开始新波不等于重开：有效的未激活道具按剩余寿命保留，过期规则仍生效。清波必须同时满足存活敌人数为零和待生成敌人数为零，不能在两批之间提前进入下一波。
