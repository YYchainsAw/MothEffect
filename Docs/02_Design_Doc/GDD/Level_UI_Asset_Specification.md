# Moth Effect（飞蛾效应）：关卡、界面与资源规格

游戏名：Moth Effect（飞蛾效应）｜v0.12｜2026-10-07。魔法朋克风格与 v0.9 玩家动画方案已由用户确定，MothEffect 第三人称模板工程已建立。本文用于单人 UE5.8 灰盒与资源制作；具体布局、数量、配色和展示节奏仍为**建议基线，待原型验证**。交互以 [道具与交互规则](Device_Interaction_Rules.md) 为权威，战斗与机关数值以 [玩法参数基线](Gameplay_Parameters.json) 为权威，本文不复制参数表。目前没有本作主竞技场或实测结果。

## 0. 魔法朋克表现方向

建议场景为灵光工坊：粗糙金属框架、铜色连接件、管线与发光符文并置，魔法能量具有可见传导方向。蛾翼轮廓用于徽记、机关外壳和界面图标，光点沿弹道传递，机关接续点亮，呼应名称与连锁主题。具体世界观、色板和道具称呼尚未冻结。

| 玩法 ID | 魔法朋克呈现建议 | 必须保留的辨识与因果 |
|---|---|---|
| W01 主武器 | 魔导步枪，枪口短符文闪光 | 命中反馈不遮准星，射击仍按原命中规则 |
| D01 弹射装置 | 青蓝三角棱柱、竖直符文，激活地脉机械柱 | 地面落点与向上箭头清楚，净空后实体阶段变化可见 |
| D02 爆炸装置 | 橙色球形晶核、环形封印破裂 | 爆心、危险范围和推力方向可理解 |
| D03 发射装置 | 紫色长方咒印枪管、箭头符文 | 锁定世界方向可见，飞行机身与直线弹道区分 |
| 敌人 | 模板角色加魔导构装背包 | 一套 AI，三种背包预告固定掉落 |

灰盒阶段只需模板人物、基础几何体、一套统一材质、三种自发光色和少量反馈。魔法朋克风格不增加新技能、召唤、蛾群 AI 或飞行系统；资源制作仍按原 P0/P1 优先级执行。

## 1. 先建验证房，再扩建竞技场

坐标使用米，原点在房间中心，X 为横向、Y 为纵向、Z 为高度；下文坐标是编辑器摆放建议，不是独立的运行时参数来源。模型先用基础几何体，墙面保持低对比，机关和弹道占视觉重点。

### 20×20 验证房 L01

范围 X/Y 均为 [-10,10]，地面 Z=0。玩家起点 (-8,0)，正前方留贯通视线。最初只放一个方块靶：D03 放 (-4,0)，D02 放 (0,0)，靶放 (2.5,0)，检验“发射器弹丸启动炸弹”。第二轮用拾取和投掷代替地面 D03；第三轮加入 D01，把 D02 摆在其柱体覆盖处，测试搬运进弹道。

北侧 (0,6) 和南侧 (0,-6) 各放一块矮掩体，先避免遮挡主测试线；墙内不设沟槽、台阶、狭门。房间入口旁放重置按钮，恢复玩家、靶和三件道具，便于连续重复测试。通过条件：玩家能理解并重复一次空中激活、一次间接启动；失败能从方向、遮挡或时机解释，不能靠隐藏触发器完成连锁。

### 60×50 主竞技场 L02

范围 X=[-30,30]、Y=[-25,25]，连续分成三区，不在区界放墙。玩家起点 (-22,-18)，三波共用整张场地。

| 区域 | 坐标范围 | 摆放与目的 |
|---|---|---|
| A 起步区 | X=[-30,-10] | 两块矮掩体中心 (-22,-5)、(-16,8)；留平地学习投掷与射击，退路连接南侧 |
| B 连锁区 | X=[-10,10] | 矮掩体 (-5,-8)、(5,8)，高掩体 (-6,6)、(6,-6)；横向和斜向都能建立射线，避免单一路口解法 |
| C 压力区 | X=[10,30] | 矮掩体 (16,-8)、(22,8)，高掩体 (24,-5)；短平台中心 (18,12)，可从两侧走坡道，提供空中机关的观察角度 |

掩体建议矮高分别约 0.9/1.8 米，平台约 1.2 米；实际以越肩镜头、敌人射线和移动碰撞验证后回写配置。掩体不横断整区，南北各保留一条约 4 米的回转通道。起点附近不能同时承受三个出生方向的射线。除外墙外，不放无法跨越的连续高墙；不设只有弹射才能逃离的坑。柱子上方留开放空间，避免玩家被送入天花板或不可达墙顶。先用侧向移动、射击和投掷逐块验收，再加装饰。

## 2. 三波流程和掉落安排

P0 只使用 BP_EnemyBase 的同一套射击 AI；三种外观只预告固定掉落，不能让玩家误以为对应三种攻击能力。清空上一波后再开下一波，始终满足存活敌人不超过 8；下面是关卡内容数量，调整时同步波次配置。

| 波次 | 确切数量与掉落 | 出生安排及学习目标 |
|---|---|---|
| 1 | 4 人：D01×2、D02×1、D03×1 | A/B 边缘出场；D03 变体位于可见位置，先杀敌取得机关，建立一条主动火线 |
| 2 | 6 人：D01×1、D02×2、D03×3 | B/C 边缘分两批各 3 人；把掉落带到三区连接处，练习搬运和间接启动 |
| 3 | 8 人：D01×2、D02×3、D03×3 | 场地边缘分两批各 4 人；通过回转通道换射击角度，形成多种连锁路径 |

每波标注出生位置，敌人不在玩家近旁或镜头背后立即开火；出生提示先出现，进入场内后才进入攻击流程。教程奖励的三件道具在教程结束时清理并重置，正式波次重新计数，避免教学物资污染波次平衡。

建议出生标记 S1=(-18,18)、S2=(-8,18)、S3=(8,18)、S4=(-8,-16)、S5=(18,18)、S6=(26,2)、S7=(18,-18)、S8=(2,-18)。波1使用 S1至S4，掉落依次 D01/D01/D02/D03；波2第一批 S2/S3/S5，掉落 D01/D02/D03，第二批 S4/S6/S7，掉落 D02/D03/D03；波3第一批 S1/S3/S5/S7，掉落 D01/D02/D03/D03，第二批 S2/S4/S6/S8，掉落 D01/D02/D02/D03。批次间隔从 [Gameplay_Parameters.json.flow.batchSpawnDelaySeconds](Gameplay_Parameters.json) 读取；位置与掩体冲突或距离玩家过近时暂缓该点生成，不在玩家背后突然替换到另一个未提示位置。进入场内后重新计算准星视线，不隔墙射击。

生成前的安全距离、预警时长与重试间隔从 [Gameplay_Parameters.json.enemy](Gameplay_Parameters.json) 对应字段读取。被占用的生成点保留待生成记录并提示入场警戒圈，玩家离开后重新预警生成；清波要同时检查存活与待生成计数。不能因当前没有存活敌人就跳过尚未出场的第二批。

## 3. 教程与越肩界面

教程建议仅三步，完成当前动作才显示下一条：①射击 D02，观察炸弹波及敌我，并用 D01 弹起方块靶；②用 E 拾取 D03，左键投掷，松开该次左键后再按左键，命中空中道具；③让 D03 的弹丸启动预置 D02，完成一次间接击杀。第二步失败可立即补发道具，第三步失败可重置阵列；不要求新手第一次就完成整套连锁。

P0 HUD：中心准星及道具命中高亮；左下生命；右下当前弹药/换弹状态；顶端波次和剩余敌人；持有时显示“左键投掷／E 放下”。可拾取提示仅给距离内、视线可达的最近目标。Held 不显示“可射击激活”提示。

投掷前显示从实际出手点指向初速度的短箭头，不能用镜头前方代替阻挡检测；出手受阻时给明确提示。瞄准 D03 时显示沿预计命中弹飞行方向的短射线，激活后用发光枪口固定方向；瞄准 D01 时在可承托地面显示落点圈，解释空中击中也会在下方伸柱。完整抛物线预览属于 P1，不阻塞首个可玩版本。

建议色形共同编码：D01 青色＋向上三角棱柱；D02 橙色＋球体/爆炸环；D03 紫色＋长方枪管/方向箭头。敌人背包沿用对应形状，UI 同时显示 D01/D02/D03 图标。Dormant 常亮轮廓、Active 脉冲/运动、Spent 暗下并消失；色彩不能成为唯一状态证据。敌人起手闪光、低速弹丸轨迹和危险范围应优先于装饰特效。

## 5. 十秒展示镜头提案

在 L01 先调成可重复的真实操作：0–2 秒拾取并抛出 D03；2–3 秒空中击中它，镜头看见定向火线；3–4 秒射击预置 D01，把其上方 D02 弹进火线；4–5 秒 D03 弹丸启动 D02，爆炸击败靶/敌人；5–10 秒保留全景与新掉落，显示因果链。连锁动作需发生在 D03 的有效发射窗口内。距离和射击时机必须先实测调整，不能用录像专用脚本自动触发机关来冒充系统连锁。若空气中的轨迹难以稳定命中，先演示地面连锁，再单独展示一次空中激活，不以宣传镜头倒逼复杂系统。
