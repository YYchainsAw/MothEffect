## 3 风险与处理顺序

| 风险 ID | 具体风险 | 先验证什么 | 处理顺序 |
| --- | --- | --- | --- |
| RISK01 | 投掷物出镜或难以瞄准 | 连续十次投掷与空中启动 | 轨迹、相机、尺寸、命中判定 |
| RISK02 | 火线方向难以理解 | 玩家能否预判一枪启动结果 | 箭头与延迟，再调整方向规则 |
| RISK03 | 只有独立效果，没有连锁利用 | 不同布局能否复现组合 | 触发共用、推力与布局 |
| RISK04 | 模板动画不足以表达动作 | 无定制动画能否看懂持有与抛出 | 手持位置、姿态与短反馈，再补动画 |
| RISK05 | 多体推力与弹丸失控 | 安全上限下计数与帧率 | 去重、生命周期、上限、效果预算 |
| RISK06 | 完整闭环进度被美术挤占 | G3 是否按期通过 | 先完成 P0，减少 P1 |
| RISK07 | 最后才发现无法打包或过审 | G0 小包与认证状态 | 第一阶段打包，提前提交 |

修改规则时遵循 [文档维护与变更流程](../../../05_Development_Guide/Documentation_Workflow.md)，历次变更记录见 [变更日志](../../../05_Development_Guide/Changelog.md)。
