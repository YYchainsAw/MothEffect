# motheffect：开发任务与排期

版本：v0.5｜更新日期：2026-10-03｜时间：香港时间（UTC+8）

当前状态：前期文档已更新，用户已建立第三人称模板工程，工程声明与模板目录已静态核对。环境运行、核心玩法、包体、试玩和投稿均未验收。T02 的工程创建子项已完成，编译与独立打包待验证；T03 的 Git/origin/忽略/LFS 已配置，提交与恢复待验收；其余任务没有完成证据。日期是建议目标，不代表实际进度。

## 1. 如何使用这份计划

每天从最早未通过的门槛开始，只做依赖已完成的任务。任务先进入“进行中”，满足可观察完成标准并留下证据后才改为“完成”。一段录屏能证明几个规则时可以共用证据，不必重复制作材料。

玩法按 [游戏策划案](../02_Design_Doc/GDD/Game_Design.md)，规则按 [道具与交互规则](../02_Design_Doc/GDD/Device_Interaction_Rules.md)，实现按 [技术设计](../02_Design_Doc/TDD/Technical_Design.md)，关卡、AI、波次和资源按 [关卡、界面与资源规格](../02_Design_Doc/GDD/Level_UI_Asset_Specification.md)，所有数值以 [玩法参数基线](../02_Design_Doc/GDD/Gameplay_Parameters.json) 为唯一基线。测试编号见 [测试计划与验收](../06_Test_Doc/Test_Plan.md)，G4 的平台步骤与审核状态见 [发布检查清单](../07_Release/Release_Checklist.md)。

单人开发允许顺序调整；门槛和任务依赖决定是否能够继续扩展。不要一边验证核心，一边同时制作成套独立角色、持枪动画、投掷动画或装饰场景。

## 2. 时间预算与必须保住的内容

**待确认的排期假设：每天实际可开发 4–6 小时，已具备基本 UE 与 C++/蓝图使用能力。** 这不是用户承诺。10 月 2–17 日共 16 天，可用 64–96 小时；保留至少 15% 故障与返工缓冲后，净实施预算约 54.4–81.6 小时。安装下载、工具链故障、陌生功能学习、资产授权查验和重新审核均可能进一步占用时间。

下表 T01–T27 合计 **50.5–82.5 小时**，是粗估区间而非承诺。上界略高于高时间预算下的净实施额度，也明显高于每天 4 小时的净额度。实际接近上界时，必须压缩允许裁剪的工作，不能靠假定每天额外工作抵消超支。T28 为 10 月 18–20 日另预留的 4–8 小时审核修复，不计入首版开发合计。可选开发日志另需约 2.5–5 小时；若争取对应奖项，应从净预算里先扣除。

不可裁剪的核心是：一把主武器、三种装置、拾取投掷与空中射击启动、装置间真实规则连锁、一张主竞技场、一套射击 AI 的三种掉落外观、三波完整胜负流程、重开、最低必要反馈和可启动的 Windows 包体。不能把延期结果降成只有普通第三人称射击的游戏。

可压缩的是：场景装饰数量、特效层数、非必要声音变化、录屏剪辑、额外外部试玩人数、外观精细程度。P1 内容（第二套冲撞 AI、五波、轨迹预览等）默认不进入本计划；多地图、Boss、成长树、移动端、联机均延期。

## 6. 超时后的取舍顺序

每天结束时重算“剩余净时间”和“剩余任务粗估”，包含尚未解决的缺陷。剩余工作下界都超过剩余时间时，当天减范围，不能等到最后两天。

1. 先取消所有 P1、额外敌人行为、额外波次和额外道具；这些本来就未列入首版。
2. T20 只保模板角色与几何体统一颜色；删独立定制动画和装饰，T19 保方向/伤害/激活信息即可。
3. T22 从 3 人减至 1 人；T26 用清楚的原始实机视频和截图，少做剪辑。不得删除外部操作观察或平台要求的物料。
4. 主竞技场保三个可辨认区域和可用投掷/弹射空间，用更少掩体降低导航、碰撞和装饰工作；仍是一张主竞技场，不增加关卡。
5. 降低同时敌人数、同时活跃机关及视觉粒子密度，但须同步修改 [玩法参数基线](../02_Design_Doc/GDD/Gameplay_Parameters.json)，并回归三波节奏和上限测试；保持三类道具、三波闭环与真实连锁。
6. G1 或 G2 延期超过一个开发日时，暂停其他内容，优先修核心。不把未达到核心标准的版本包装为完成；更新时间、未实现项和风险。

如果实际每天只有 2–3 小时，10/2–17 只有 32–48 小时，扣缓冲后不足下表粗估下界。此时原三波参赛版不能被保证：应先集中约 4–6 个开发日完成 G0–G2，确认剩余时间后重估。保住可运行核心原型和真实连锁的价值，再决定参赛版能否完成；不要为赶截止删除本作特色。
