## 1. 运行时与保存资产

`AEnemyBase` 使用内建AIController与CharacterMovement，复用HealthComponent、ExternalImpulseComponent和正式P01，不依赖模板Combat的近战StateTree。Config/DefaultGame.ini是参数账本enemy的运行时副本。保存`/Game/MothEffect/Enemies/BP_EnemyBase`引用已有`BP_RuleProjectile`，原生灰盒Cube、红色FIRING文字和方向箭头提供最低预警；角色Capsule唯一接收命中，装饰网格无碰撞且不影响导航。

生命60，W01普通伤害20，通常三次有效命中击杀；预警0.5s，射击尝试间隔1.2s，预警包含在相邻尝试之间。每次完整预警后再次检查目标/视线/权限/枪口净空，再用共用P01生成入口；容量满或出生受阻消耗该次尝试，迟帧不补发。已经发出的弹丸继续自己的3s寿命，不因发射者死亡被取消；只有生成者被忽略，没有同阵营免伤。普通道具在射出后进入弹道仍可被该P01启动；挡住视线的道具也会阻止后续瞄准。

全向视距2500cm，攻击距离1800cm，移动300cm/s。只攻击同World存活且启用的目标；失去视线仅追最后可见位置，记忆3s，不隔墙更新真实位置。无有效导航时不穿墙直追；每0.5s重试，1.5s无至少10cm进展时交替尝试侧向500cm导航点，并保留绕行目标到达/超时，避免每次重寻路又撞回原障碍。动态柱子/机关不重建NavMesh；无法到达的最终关卡区域仍须T17修布局。

死亡先提交Dead/幂等标记，停导航/预警/推力并关闭Capsule，再广播一次`OnEnemyDied`供后续掉落接入；0.5s短反馈后清理。禁用、换目标、目标死亡、EndPlay取消预警，恢复必须完整重新预警；World暂停冻结时钟。T15的三外观/固定掉落、T16波次/敌人数量和界外注销、T17最终场地不在此轮完成。

## 2. 当前 PIE 验收清单

原工程新DLL已构建。重新打开`/Game/MothEffect/Tests/L_T14AI`并进入PIE；地图保存一个普通射击敌人、静态掩体、矮掩体、台阶/平台及已构建NavMesh，无脚本自动开火或命中。初始敌人距离约22m，会追近再预警。

| Development控制台命令 | 用途 |
|---|---|
| `MothEnemyStats` | 写出敌人血量、目标、视线、尝试/出生数、路径请求和停滞次数，屏幕显示存活数 |
| `MothSpawnEnemy` | 在玩家前方约9m生成一件保存的敌人BP，碰撞无法调整则拒绝；仅调试，不代替T16出生预警/8人波次上限 |
| `MothResetEnemies` | 删除本World全部EnemyBase；不重置玩家血量、地图、波次或已飞P01 |
| `MothResetDevices` / `MothLifecycleStats` | 沿用T13的道具/P01清理与统一容量计数 |

1. **移动与预警**：敌人在可见范围追近，停止后显示红色FIRING/方向箭头，约0.5s后飞出可见P01；连续开火不出现瞬间密集补发。核对远处/不同角度的提示是否可读。
2. **掩体与取消**：在预警中退到中央高掩体后，应取消该次预警、不隔墙生成新弹；已有弹丸被实物挡住。重新露面应先完整预警；在开阔区携带道具时也不会形成免伤护盾。
3. **追踪与导航**：在掩体两侧、不同距离和平台/跳跃状态移动。敌人沿可行走区域追踪最后可见位置，不卡在墙上持续射击；超过视距/记忆暂时失去目标属于预期，重新可见后恢复。临时非导航障碍的停滞换点另有Game自动化实测，最终竞技场导航随T17补测。
4. **击杀**：正常W01三次有效命中应击杀60HP敌人，立即停止移动/预警/新发射，DEAD短反馈后消失。当前不掉落机关，T15接入固定掉落；生前已飞的P01按原寿命/首次阻挡结束。
5. **暂停与重复进入**：预警期用PIE工具栏暂停/恢复，暂停期间不发射、恢复继续剩余预警；结束PIE后重新进入，敌人回到初始位置和60HP，没有上一轮延迟射击或控制器残留。再次生成/删除敌人应正常，无崩溃。

保留`LogMothEffect`中Enemy event/phase/health/shots/spawned/paths/stalls/time及P01 HitId记录。原生覆盖、首轮失败和导航构建边界见[T14报告](../06_Test_Doc/T14_Report_2026-10-11.md)。本清单通过后才补齐#16当前PIE验收；完整TC21、正式场地、独立包与G3仍按后续证据验证。
