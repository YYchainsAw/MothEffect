# Moth Effect：T18 HUD、教学与菜单接入

版本 v0.1 · 2026-10-12 · 状态：已接入；当前硬件输入与完整图形 PIE 待验收

打开 `/Game/MothEffect/Maps/L_Arena_01` 后 Play，从标题页选择“开始教学”或“直接进入竞技场”。标题、暂停、教学完成、胜利和失败使用同一套面板；不需要输入控制台命令。T16/T17 的 [PR #45](https://github.com/YYchainsAw/MothEffect/pull/45) 保持原有待校验状态，T18 当前仅在本地 develop 开发。

当前入口优先教学但允许主动直接开战；参数账本原有 `flow.tutorialRequiredFirstRun=true` 尚未接入首次教学持久化锁定，这一 UI 差异已记录在 T18 报告与参数账本。

## 接入与数据

- `AMothEffectPlayerController` 在拥有本地正式玩家、步枪及地图导演后创建 `WBP_MothHUD`；无导演的旧独立验证场保留其输入流程。新 Widget Blueprint 继承 `UMothHUDWidget`，布局由原生 UMG WidgetTree 创建。
- 首次绑定主动读取 Health、Rifle、Held、WaveDirector 和 Tutorial 的 getter；生命、弹药、动作、波次、教学事件更新显示。连续换弹进度、准备倒计时、准星候选和短提示由当前世界的时间读取。换玩家时解绑旧来源，Widget EndPlay/NativeDestruct 清理绑定。
- E 的候选是准星射线第一个阻挡命中的 Dormant 道具，满足距离、持物挂点、动作和两条无遮挡检查；HUD 复用只读候选查询，不改变 T07 交互。Held 只提示投掷/放下，不提示射击启动。
- 菜单使用 UIOnly、显示鼠标并将键盘焦点交给主按钮；教学/战斗使用 GameOnly、隐藏鼠标并恢复视口焦点。Esc 暂停/继续；按钮可用 Tab/方向键、Enter/Space 操作。暂停停连射、冻结世界合法任务；继续不会伪造投掷后的实际松键。
- 进入正式战斗先清理教学并 OpenLevel 重载当前关卡。`UMothGameInstance` 仅保留一次“新世界开始战斗”的意图，成功进入 Preparing 后消费；生命、弹药、持物、教学状态、波次、对象与绑定仍归各自世界。结果“重新开始”回到全新标题，不自动再开战。

## 三步教学

| 步骤 | 实际目标 | 失败与重试 |
| --- | --- | --- |
| 1 爆炸与抬升 | W01 启动橙色 D02，真实爆炸击败方块形静止角色靶；W01 启动青色 D01，真实物理箱子上升超过教学起始高度 100cm | 两个目标分别记录，可换顺序完成；直接射死角色靶不算爆炸目标。按“重置本步道具”重新布置 |
| 2 空中启动 | E 拾取 D03，左键真实投出；松开该次按压，恢复后新按压 W01 命中空中 D03 | E 放下、地面启动不能推进；错误启动、投出后落地或道具失效会补充并显示提示。持有时不能射击启动 |
| 3 间接连锁 | 沿紫色箭头从左向右击中 D03，真实 P01 启动预置 D02，爆炸击败靶 | W01 直接启动 D02 不算间接目标；失败可重置本步阵列。启动瞬间锁定方向，后续移动准星不会追踪 |

三步都依赖提交后的动作、激活来源、物理高度和真实死亡来源。教学观察回调只记录证据，换步骤在世界计时器中发生，避免在机关命中回调内销毁连锁来源。完成、退出、死亡、界外或重开清理本教学拥有的道具、靶和方向标记；进入正式战斗不携带教学奖励。

## 图标与样式源

[样式账本](../../SourceArt/UI/T18_Style.json)、[D01](../../SourceArt/UI/D01_Launcher.svg)、[D02](../../SourceArt/UI/D02_Bomb.svg)、[D03](../../SourceArt/UI/D03_Emitter.svg) 为本项目原创源码。运行时 `UMothDeviceIcon` 在 Slate 中画对应矢量线条，缩放不依赖位图。青色上箭头、橙色带射线圆环、紫色枪管箭头同时使用颜色和轮廓，类型与已有敌人标记/掉落一致。

暗青底、浅米文字、铜色信息，Roboto Bold 标题、Regular 正文和 BoldCondensed 小标签；中文使用引擎复合字体回退。教学按文字实际高度排版，准星有描边，交互/失败提示有暗底，键盘焦点始终可见。以 1920×1080 为参照，SafeZone、锚点与工程 DPI 规则处理 1280×720 / 1920×1080 / 2560×1440。三种实际分辨率和字符显示以交付报告中的渲染证据为准；独立包字体仍需 T21 验收。

仅新建 `/Game/MothEffect/UI/WBP_MothHUD`，不改已有玩家或控制器蓝图。重建入口为 [create_t18_ui.py](../../scripts/create_t18_ui.py)，脚本只认领并保存自己的包，不使用 SaveAll。C++ 构建后可用 Editor Python 执行；只有 `T18_UI_ASSET_VERIFIED` 与保存类检查都成功才算资产验证通过。

## 当前用户 PIE 验收

以下五组目前未记通过，测试时使用当前 `L_Arena_01` 和实际 Murdock 玩家：

1. **入口与显示**：分别用 1280×720、1920×1080、2560×1440 窗口打开标题。检查中文、三图标、全部按钮无裁切；鼠标点按、Tab/方向键、Enter 可用。开始教学后生命 100、弹药 24，准星与提示无遮挡。
2. **真实三步教学**：逐步完成爆炸靶/箱子抬升、拾取投掷/松键再射击、空中启动和 D03→D02 间接击杀。第二步先尝试放下后启动、投空后落地；应补充并停在本步。第三步直接打 D02 不能通过，重置阵列后完成。改变准星后 D03 方向仍锁定。
3. **实时 HUD 与交互**：受伤、开火、空弹匣、R 换弹、拾取、E 放下、左键投出。数字/换弹条/图标与实际一致；墙后、远处或 Active 道具不显示可拾取，Held 不显示可启动；前方受阻时仍携带并显示原因。
4. **暂停与输入**：按住开火、换弹中、投掷恢复中、持物中分别 Esc 暂停，等待超过任务时长。菜单可鼠标/键盘操作，世界冻结；继续不误射，换弹保留剩余时间，投掷仍需实际松键后新按压。切出窗口再回来同样不连射。
5. **胜负与重开**：教学完成后开始战斗，恢复 100HP/24 弹且无教学道具；直接开始竞技场同样正确。通关三波见胜利/重新开始；战斗死亡、教学死亡或越界见失败。暂停返回入口、胜负重开各反复执行，均回到干净标题，无旧波数/持物/对象或重复响应。

用户确认后按实际范围更新 [T18 报告](../06_Test_Doc/T18_Report_2026-10-12.md) 与 [#20](https://github.com/YYchainsAw/MothEffect/issues/20)。外部盲玩 TC26 留在 T22，独立包与完整 G3 留在 T21/后续门槛；原生测试和助手渲染检查不代替用户硬件输入验收。
