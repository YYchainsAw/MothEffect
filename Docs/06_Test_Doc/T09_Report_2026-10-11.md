# Moth Effect（飞蛾效应）：T09 收尾与验证报告

版本 v0.2 · 2026-10-11 · 状态：构建、原生 Automation 及当前 PIE 验收通过；T09 已完成

PR 标题：`fix: 收尾 T09 输入中断与玩法任务清理`

## 改动与目的

原有单次投掷、恢复计时、暂停与换弹取消机制已实现。本轮用原生角色执行边界回归，复现并修正两处缺口：

- 应用失焦但没有收到 viewport Flush 时，步枪定时器仍可续射。角色 Tick 在应用失焦时取消当前按压并复位移动输入，射击许可也检查焦点；重新获得焦点仍需实际松键和新按压。已有 Controller Flush/SetPause 入口继续使用。
- 控制器解除控制后，旧角色仍可续射。UnPossessed 现在停止连射、取消换弹与投掷恢复、清理 Held 和移动输入；取消任务不补弹，不产生额外掉落。
- 初始化释放查询的向量输出，消除该函数的 C4701 编译警告。玩法数值、碰撞规则和动画资产没有调整。
- 新增九项 `MothEffect.Player.T09` 测试。测试角色为不可放置的编辑器专用对象，使用引擎 SkeletalCube，不依赖项目 BP/ABP；仅硬件按键与应用焦点使用确定性替代，伤害、拾取验证、阻挡查询、状态与世界计时调用实际实现。
