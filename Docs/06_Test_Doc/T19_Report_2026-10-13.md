## 本轮交付

- `UMothFeedbackSubsystem` 按已提交动作发出十二类反馈，提供命中/受伤两个 Blueprint Alpha；世界视觉和声音有独立预算。暂停拒绝新增反馈并冻结寿命/声音；结算、管理对象重置、世界结束同步清理瞬时效果、音频和屏幕反馈。
- `AMothFeedbackVisual` 用真实静态网格绘制枪口/碰撞短闪线、D01 上升线、D02 实际爆炸半径分段环与失败/Spent X；反馈网格无碰撞、Overlap、导航影响或阴影。D02 仍立即爆炸，反馈没有新增引信。
- 每个机关原生 `DefaultFeedback` 提供青色上箭头、橙色菱形、紫色侧箭头；Dormant 常亮、Active 慢脉动、Spent 灰色小 X、过期黄色快脉动。Held 隐藏轮廓；D03 Active 箭头沿提交时世界方向锁定，跟随道具平移，独立于物理滚动。
- HUD 原生绘制短命中 X 与受伤边线，无需新增必需 Designer 控件；可关闭 `bDrawDefaultCombatFeedback` 并读取 Alpha 自制 UI。全局 Profile / 世界视觉 / 音频和单机关轮廓均可分别关闭。
- 实际渲染发现 T18 保存的共享字体来源重载后缺失，导致文字显示方框；`NativePreConstruct` 仅给缺失来源的文字恢复默认字体，保留用户指定的有效字体、字号、描边、颜色和布局。没有重存 HUD 或玩家蓝图。
- `/Game/MothEffect/Feedback` 保存十一件资产：`DA_DefaultFeedback`、发光材质、空间衰减与八个原创短音效。源声音由 Python 标准库合成，48kHz mono 16-bit PCM，0.07–0.36s，没有第三方录音/样本；[来源账本](../../SourceArt/Feedback/AudioManifest.json) 保留文件 SHA256。
- [资产脚本](../../scripts/create_t19_feedback.py) 仅创建缺失资产，已有用户修改保留；[音频生成脚本](../../scripts/generate_t19_audio.py) 可重现原始 WAV。默认反馈目录已 Always Cook；声音、材质、体积、时长和强度由 Data Asset 调整，不改战斗规则参数。
