# Moth Effect：T20 可替换机关与场景原型报告

版本 v0.1 · 2026-10-13 · 状态：原型实现、构建与自动化完成；五组用户验收待执行

任务 [#22](https://github.com/YYchainsAw/MothEffect/issues/22) 交付三种机关外壳、一个掩体模块、一个符文灯饰及共用材质。按用户最新选择，当前作品作为其后续深度修改机制与全部替换 UI 的可运行基线；制作和配置见 [Prototype_Art_Setup](../05_Development_Guide/Prototype_Art_Setup.md)。

## 交付与边界

- 五件原创低模、两个母材质、九个实例和 `DA_PrototypeArt`，共十七件保存资产。D01 向上棱柱底座、D02 晶核/封印环、D03 定向枪管，铜饰与类型发光色共用原型材质体系。OBJ/MTL、原创来源与 SHA256 在 [制作清单](../../SourceArt/PrototypeArt/PrototypeArtManifest.json)，[生成脚本](../../scripts/generate_t20_art.py) 标准库即可复现。
- Profile 提供三种设备模型/材料/局部 Transform、掩体与灯饰开关、选择尺寸、布置和局部光参数。`DeviceMesh` 只负责显示；物理/射击球、质量、伤害、计时和发射方向继续归现有玩法。敌人从实际掉落类的同一 `GetVisualAppearance()` 解析背包，保留类型匹配门控。
- `bUsePrototypeAppearance` 与 `PrototypeArtProfile` 支持按类/实例替换。关闭后恢复覆盖前外观；直接用户替换优先保留。材质列表默认对应 Metal/Copper/Glow 语义槽，按名字分配以适应 importer 重排；可以关闭语义映射使用自有索引。
- 主 GameMode 在 `L_Arena_01` 生成一个可关闭场景层，装饰六块矮掩体与三块高掩体、北侧三件符文灯饰。原 Cube 继续负责遮挡、导航与承托，装饰不参与碰撞/Overlap/导航；刷新、关闭和销毁恢复原可见性。没有保存或覆盖主地图、既有机关/敌人/HUD/玩家蓝图。
- 默认目录纳入 Always Cook；玩法参数仍为 v0.18。当前原型尺寸和规则可由用户后续修改，同步实际配置、对应文档与测试即可；本轮没有完成独立包或全面 UI 重做。
- 新一轮 Unity 构建发现 T19 上升线的局部 Rotation 未初始化（C4701），补为 ZeroRotator；既有反馈六项与真实 FeedbackRuntime 随本轮回归，不扩大用户 T19 手动验收范围。
