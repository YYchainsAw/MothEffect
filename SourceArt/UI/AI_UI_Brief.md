# Moth Effect：AI 辅助 UI 制作清单

日期：2026-10-14。依据当前本地开发计划、T18/T19 接入说明、UI 源码以及已归档的 T18/T21 游戏截图整理。本文是制作建议，不修改玩法或任务验收状态；实际行为以当前代码及权威设计文档为准。

## 1. 当前基础与制作范围

游戏是 Windows 键鼠操作的魔法朋克第三人称越肩射击：击败敌人取得三类机关，拾取、投掷、射击启动，利用真实弹丸与物理形成连锁，完成三波战斗。

当前代码已经定义七种页面状态：Title、Gameplay、Tutorial、Pause、TutorialComplete、Victory、Defeat。一个 `WBP_MothHUD` 提供基础控件树，主要页面动作与真实数据更新已接入。2026-10-13 的编辑接口交付记录为 54 个控件、25 个必需绑定；本次未打开编辑器重新检查资产树或执行游戏验收。

制作可以围绕三套结构复用：战斗 HUD、叠加在 HUD 上的教学面板、标题/暂停/教学完成/胜负共用的菜单面板。七种状态不意味着需要七张完整背景或七个独立蓝图。

## 2. 首版必需页面

| 页面状态 | 必须展示的内容 | 视觉制作范围与现有动作 |
| --- | --- | --- |
| 标题 Title | 游戏名、简短玩法介绍、三机关识别、开始教学、直接进入竞技场、退出 | 共用菜单的入口状态；可增加蛾翼徽记和工坊背景插画 |
| 战斗 Gameplay | 中央准星、生命数值与条、当前弹药/弹匣容量、换弹进度、波次、准备倒计时、场内/待入场敌人数、持物与操作提示 | 一套 HUD；生命左下、弹药右下、波次上方是当前布局，可以调整 |
| 教学 Tutorial | 战斗 HUD、教学步骤 1/3–3/3、当前目标、重置本步道具、失败与补充提示 | 共用教学卡片，实际完成目标后推进 |
| 暂停 Pause | 暂停状态、继续游戏、返回入口、退出 | 共用菜单；突出继续操作与键盘焦点 |
| 教学完成 TutorialComplete | 完成说明、开始战斗、返回入口、退出 | 共用菜单的完成状态 |
| 胜利 Victory | 三波完成说明、重新开始、退出 | 共用结果面板；现有重新开始返回全新标题 |
| 失败 Defeat | 挑战结束说明、重新开始、退出 | 与胜利共用结构，改变标题、强调色或装饰 |

现有结果页没有分数、连杀、连锁次数等统计接口。这些内容如需展示，应先增加统计功能，再扩展结算设计。

## 3. HUD 必须覆盖的状态

| 组件 | 需要设计的状态 | 数据或交互含义 |
| --- | --- | --- |
| 准星 | 普通、指向未启动机关、确认命中 | 三机关候选使用各自类型色；确认命中已有短白色 X |
| 生命 | 正常血量、受伤、死亡 | 数值与填充随真实生命更新；受伤已有屏幕边线 |
| 弹药 | 正常、空弹匣、换弹中 | `24 / 24` 表示当前弹匣/弹匣容量；备用弹药不耗尽，空匣需按 R 手动换弹 |
| 波次 | 准备倒计时、战斗中、存在待生成批次 | 同时表达场内和待入场人数，避免空窗被理解为清波 |
| 持物 | 空手、持有 D01/D02/D03 | 空手左键射击；持物左键投掷、E 放下；投出后松开左键，再重新按下射击 |
| 交互提示 | 射击启动、满足条件时 E 拾取 | 墙后、远处或已启动机关不能提示可拾取；Held 不提示可射击启动 |
| 短提示 | 空匣、枪口遮挡、前方空间不足、教学补充与重置 | 使用可换行的统一提示条，不遮准星与主要目标 |

低血量闪烁、空匣闪烁等额外动画是视觉增强；目前可以先完成现有数值、提示与反馈的统一样式。

## 4. 三步教学需要的内容

1. **爆炸与抬升**：射击 D02，用爆炸击败靶；射击 D01，抬起物理箱。两个目标可交换顺序；爆炸也伤玩家。
2. **空中启动**：E 拾取 D03 → 左键投出 → 松开左键 → 恢复后重新射击空中 D03。放下后启动、地面启动不能完成本步。
3. **间接连锁**：射击 D03 → D03 弹丸启动 D02 → 爆炸击败靶。方向在启动时锁定，移动准星不改变发射方向。

文本、步骤编号和重置按钮已有接口。三张小示意图可作为 AI 辅助素材的后续增强：先保证箭头与实际因果一致，再加键位和说明文字。示意图随教学步骤切换需要补显示逻辑。

## 5. 场景里的信息提示

这些属于世界空间反馈，不应全部画进一张 HUD 背景：

| 表现 | 当前接入情况 | 制作建议 |
| --- | --- | --- |
| D01/D02/D03 类型与 Dormant/Active/Spent | T19 已有不同轮廓、脉动与 Spent 标记 | 与 UI 三机关色形保持一致 |
| D03 启动后的方向箭头 | 已有锁定世界方向的箭头 | 方向随位置平移，不随镜头或机身滚动转向 |
| D02 爆炸范围 | 已有爆炸时的范围环 | D02 为立即爆炸；设计对应瞬时范围反馈 |
| 敌人出生警戒 | 波次导演已有警戒圈与标签 | 保持危险提示优先级与场地可见性 |
| 机关过期警告 | 已有黄色快速脉动、声音和文字 | 保持形状/运动变化与颜色共同表达状态 |
| 投掷前短方向箭头、D03 瞄准方向预览、D01 启动前落点圈 | 资源规格提出了建议；本次源码核查未发现完整对应的运行时预览接入 | 单独排接入工作；仅制作图片不会产生预览判定 |
| 完整投掷抛物线 | 原计划 P1 扩展 | 在首版必要页面完成后再考虑 |

## 6. AI 素材与 UMG 的分工

| 交付物 | 建议数量 | 用途与优先级 |
| --- | --- | --- |
| 战斗 HUD 风格稿 | 1 张 | 最先确定信息位置、尺寸、留白与视觉语言；仅作布局参考 |
| 主菜单风格稿 | 1 张 | 定义标题和按钮体系，派生暂停、完成与胜负 |
| 蛾翼/符文徽记 | 1 个 | 透明背景装饰，文字由 UMG 单独排版；首版可选 |
| 菜单背景插画 | 1 张 | 魔导工坊、铜结构、符文传导；首版可选，也可保留游戏场景背景 |
| 三机关图标变体 | 每种 1 个 | 青上箭头、橙爆炸环、紫定向枪管；已有矢量图标可直接沿用 |
| 共用面板框与按钮装饰 | 各 1 套 | 可拉伸的面板与统一按钮；普通、悬停、按下、焦点可通过 UMG 色值变化完成 |
| 教学小示意图 | 3 张 | 可选增强，分别解释抬升/爆炸、投出后空中射击、D03→D02→靶 |
| 受伤边缘遮罩 | 1 张 | 可选替换现有红线；透明背景，中心区域透明 |

**优先批次**：HUD 风格稿 → 主菜单风格稿 → 共用面板/按钮 → 持物与交互状态 → 教学与胜负派生。图标、背景插画和教学插图按剩余时间追加。

运行素材应拆成独立装饰和透明 PNG；文字、数字、按键标签、按钮点击区域、进度条填充与显隐使用 UMG。整张效果图适合参考，动态 HUD 需要独立控件才能响应实际状态。

建议以 1920×1080 制作页面稿，沿用 24 像素基础安全边距；再核对 1280×720 和 2560×1440 的缩放、换行与按键焦点。独立图标可从 512×512 源图开始制作，最终缩小后仍需清楚。

## 7. 统一视觉建议

沿用现有色板作为初稿，最终色板由用户选择：暗青底 `#14282D`、次级底 `#34515C`、米白文字 `#F2EFE0`、铜金强调 `#D8B67A`；D01 青 `#53D6DC`、D02 橙 `#FF985C`、D03 紫 `#B592EF`。

用细铜线、蛾翼轮廓、少量符文节点连接表现魔法朋克与连锁主题。三机关以颜色加形状共同编码。HUD 保持轻量，中央瞄准区留白；当前截图的教学块位于下方中央，可缩小或移到侧边，以减少对角色和目标的遮挡。

中文正文保持高对比和可读字号；符文与纹理集中在边框及标题装饰。按钮必须有清晰鼠标悬停和键盘焦点状态。

## 8. 可复制的生成提示词

### 战斗 HUD 风格稿

> 为 Moth Effect（飞蛾效应）设计 1920×1080 的 Windows PC 第三人称越肩射击游戏 HUD 概念稿。魔法朋克风格，暗青半透明面板、米白信息、细铜金边线、少量蛾翼和符文节点。左下生命数值与细进度条，右下当前弹匣/弹匣容量与换弹进度，上方居中的波次、准备倒计时、场内和待入场敌人数，底部紧凑的持物图标与操作提示。中央保留大面积游戏视野，只放小准星与短交互提示。D01 青色上箭头，D02 橙色爆炸环，D03 紫色定向枪管箭头。主角位于画面左侧，确保 HUD 不遮中央目标。示例数据使用生命 100/100、弹药 24/24、第 1/3 波。采用适合 UMG 拆成独立组件的清晰结构，边框克制，文字区域干净。

### 主菜单风格稿

> 为同一游戏设计 1920×1080 主菜单概念稿，沿用 HUD 的暗青、米白和细铜金视觉语言。背景为具有铜管线、符文能量与机械机关的魔导工坊，菜单区域保持安静清晰。使用蛾翼符文徽记，预留 MOTH EFFECT 与飞蛾效应标题区域、两行简介、青色抬升/橙色爆炸/紫色发射三图标。纵向排列开始教学、直接进入竞技场、退出游戏三个按钮，主按钮重点明确，键盘焦点清楚。面板与按钮能够复用于暂停、教学完成、胜利和失败。保持文字、按钮与背景可拆分。

### 无文字运行面板素材

> 生成适合游戏 UMG 使用的单个魔法朋克面板装饰，透明背景，正视平面，四角少量铜金金属细线与符文节点，暗青内部保持均匀干净，中心和边缘中段具有连续可伸缩区域。无文字、无数字、无图标、无场景、无透视、无强烈外发光。与暗青、米白、铜金 HUD 统一。

概念稿中的文字只用于表达版式；运行素材导出时采用无文字版本，再由 UMG 显示实际内容。

## 9. 现有工程的接入位置

- 主入口：`/Game/MothEffect/UI/WBP_MothHUD`，父类保持 `MothHUDWidget`；七种页面可通过 Class Defaults 的 Designer Preview 查看。
- 三步教学文案：`/Game/MothEffect/UI/DA_MothTutorial`。
- 保留 `UI_Setup.md` 中列出的 25 个绑定名称与兼容类型；位置、父容器、字体和普通样式可改，新增图片可作为装饰组件。
- `HeldIcon` 当前是 `MothDeviceIcon`，三机关图标由 Slate 代码绘制。若使用 AI PNG，需要扩展图标组件或另加图片与状态同步；直接把绑定控件改为 Image 会破坏类型契约。
- `CrosshairText` 当前是 TextBlock，候选机关时代码会改颜色。图片准星需要同步自己的状态表现，并保持现有绑定可用。
- 命中与受伤已有 `MothFeedbackSubsystem` 的 Alpha 接口。自制屏幕反馈时关闭 `bDrawDefaultCombatFeedback`，用 `Get Hit Marker Alpha` / `Get Damage Edge Alpha` 驱动图片透明度。
- 基础设置页（音量、鼠标灵敏度、显示选项）可列为后续增强；当前七页面流程尚无设置页及其菜单入口。
